01工具简介 Overview

foundry-quota-sentinel 是一个独立的多服务商 LLM 额度监控工具（前身 ocgt-monitor）。它通过各服务商的网页接口查询用量：OpenCode Go RPC、DeepSeek 余额与用量接口、Ollama Cloud 会话接口、Kimi Code 额度接口，凭证由内置的浏览器登录流程自动抓取。Most features work independently; only the history/trend feature reads local JSONL log files.

核心特性 Key Features
• 四家服务商：OpenCode Go · DeepSeek · Ollama Cloud · Kimi Code
• 多账户并行展示，单账户失效只影响该卡片
• 浏览器一键登录，自动抓取 Cookie / Token，免手动 F12
• 右键卡片直达对应账户的官方管理页面
• 双主题：亮色「灵动卡片」与暗色「深色专业」
• 跨平台：Windows 贴边自动隐藏侧边栏，macOS / Linux 独立窗口

02快速开始 Quick Start

1

下载程序 Download

从 Releases 下载对应平台的二进制。Download the binary for your platform from GitHub Releases.

2

添加账户 Add an account

双击启动后，点面板底部「添加账户」卡 → 选择 OpenCode、DeepSeek、Ollama 或 Kimi → 在弹出的浏览器窗口中登录，凭证自动保存。Click the "Add account" card, pick a provider, sign in — credentials are saved automatically.

也可使用对应的命令行：login-opencode / login-deepseek / login-ollama / login-kimi。

3

双击运行 Double-click to launch

直接双击二进制，桌面侧边栏即刻启动，无需终端。Just double-click the binary — the sidebar appears on your screen.

也可在终端运行 foundry-quota-sentinel serve --sidebar 或 foundry-quota-sentinel quota 等命令。

!
PowerShell 用户注意： 命令前需要加 .\ 前缀，例如 .\foundry-quota-sentinel login-deepseek 我的号。PowerShell requires .\ prefix for local executables.

04桌面侧边栏 Desktop Sidebar

桌面侧边栏是推荐使用方式：半透明面板呈现一列账户卡片。Windows 上是贴屏幕右缘、自动隐藏的停靠侧边栏；macOS / Linux 上为普通独立窗口。A translucent panel of account cards. Edge-docked auto-hiding on Windows; a standalone window on macOS / Linux.

启动方式：双击二进制，或在终端运行 foundry-quota-sentinel serve --sidebar。

账户卡片 Account Cards

卡片自上而下排列：OpenCode Go 账户在上、Ollama 与 Kimi 账户居中、DeepSeek 账户在下、底部为「添加账户」卡。

OpenCode Go

Rolling / Weekly / Monthly 三条额度进度条，80% 变橙、95% 变红预警。多账户同时展示，单账户失效只影响该卡片。

DeepSeek

账户余额 + 当月「按模型」每日 token 用量图（echarts 堆叠柱：命中缓存 / 未命中 / 输出）。

Ollama Cloud

Session / Weekly 使用率与重置时间，凭证由一次性浏览器登录自动获取。

Kimi Code

总用量条内黑色段标 Kimi、蓝色段标 Code；另列 5 小时与 7 天 Code 用量及绝对重置时间。「购买加油包」直达官方页面（不自动购买）。

05浏览器登录 Browser Login

四家服务商的登录统一走内置的 internal/browserauth 流程：启动本机已安装的 Chrome / Chromium / Edge 的一个一次性临时配置窗口，通过回环地址上的 Chrome DevTools Protocol 抓取凭证，成功后立即关闭浏览器并删除临时 profile，不读取日常浏览器数据。A one-shot temporary profile captures credentials via CDP; your everyday browser profile is never touched.

OpenCode Go / DeepSeek

登录后自动保存 Cookie / 网页 Token，无需手动 F12 复制。

Ollama Cloud

需要 Chrome / Chromium / Edge 在 PATH（Linux 已验证 Edge）。抓取会话 Cookie 后即删临时 profile。

Kimi Code

抓取 accessToken + durable refresh token，回放受保护接口确认鉴权后才保存。accessToken 约 15 分钟过期，之后用 refresh token 自动续期，无需频繁重登。

隐私

Kimi 凭证以版本化的最小 auth envelope 保存，仅含回放必需字段；所有凭证只存在本机用户目录。

06配置管理 Configuration

配置存储在 ~/.foundry-quota-sentinel/config.json（Windows 为 %USERPROFILE%\.foundry-quota-sentinel\config.json），每个用户独立。四家服务商的账户分别存于 profiles、deepseek_accounts、ollama_accounts、kimi_accounts。

构建依赖（CGO）：Windows = MinGW64（gcc）；macOS = Xcode Command Line Tools；Linux = libgtk-3-dev libwebkit2gtk-4.0-dev。

# macOS / Linux 原生 GUI
go build -ldflags="-s -w" -o foundry-quota-sentinel .

# Windows GUI（见 build.bat）
build.bat

# 用 Docker 编 Linux GUI 二进制
./scripts/build-linux.sh

# 无 GUI、无 CGO（仍含 CLI 与 serve 网页面板）
CGO_ENABLED=0 go build -tags nogui -o foundry-quota-sentinel .

发行版二进制由 GitHub Actions 三平台原生构建，推送 v* tag 时自动发布到 Releases。

08常见问题 FAQ

凭证过期 / 查询报错？

Cookie / Token 可能过期。重新运行对应的 login-* 命令登录一次即可。

Ollama / Kimi 登录找不到浏览器？

需要系统已安装 Chrome、Chromium 或 Edge 且可在 PATH 中找到（Linux 已验证 Edge）。

Kimi 要每 15 分钟重登吗？

不用。accessToken 过期后会用 durable refresh token 自动续期额度查询与账户页会话。

history 无数据？

历史数据来自本地 JSONL 日志文件，需要有日志产生后才能展示。

Win10 侧边栏没反应？

需要 WebView2 Runtime。Windows 11 自带；Win10 请从微软官网安装。

Linux 没有 webkit？

用 *-linux-portable 纯 Go 静态版，运行后浏览器打开 http://127.0.0.1:8788/sidebar.html。

从 ocgt-monitor 升级？

直接换二进制即可，旧的 ~/.ocgt-monitor 配置首次运行自动迁移。

需要安装 Go？

发行版二进制可直接运行。只有需要重新编译时才需要 Go 1.26+。
